## Featured Projects

### Jobly: Personal Job Application Tracker
**Problem:** Job seekers lose track of where each application stands.

- Built **15+ REST APIs** for managing applications end to end
- Secured every route with **JWT authentication**
- Added filtering and a full **status history** per application in MongoDB

**Tech:** Node.js, Express.js, MongoDB, JWT

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit-2ea44f?style=for-the-badge)](https://jobly-track-job.vercel.app/)
[![GitHub](https://img.shields.io/badge/GitHub-Repo-181717?style=for-the-badge&logo=github)](https://github.com/rakibfeb/job-tracker-api)

### Kirkit: Live Cricket Match Management System
**Problem:** Local cricket tournaments run on paper and WhatsApp, which makes scheduling and scoring messy.

- Designed **25+ REST APIs** covering tournaments, teams, players, matches, and standings
- Built **live scoring and scoreboards** with Socket.IO
- Modeled data across **7+ MongoDB collections**

**Tech:** React, Node.js, Express.js, MongoDB, Socket.IO
